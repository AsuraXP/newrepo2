# The Rewilding — Animated Story Video

Second-person fictional survival story, decades after the collapse: the turned
no longer roam like a plague — they drift like elk through a regrown forest.
You are a rewilding ranger whose job is to catalogue a migrating herd. Then the
herd does something no manual covers.

Produced per SWARM SPEC v3.0. Audio/TTS/FFmpeg happen ONLY on Kaggle; this
workspace holds scripts, CSVs, frames and Git commits.
