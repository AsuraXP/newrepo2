# Ship Apocalypse — Animated Story Video

Second-person fictional horror-survival narrative: you board a ship during an
shore-side apocalypse; the crowds onboard and a few infections among the
passengers make it safer than land — no shore contact, and far more zombies on
land than on the ship.

Produced per SWARM SPEC v3.0. Audio/TTS/FFmpeg happen ONLY on Kaggle; this
workspace holds scripts, CSVs, frames and Git commits.
